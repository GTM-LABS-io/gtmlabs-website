🚀 Quick Install

Step 1: Download the MCP

curl -o ~/gtm-labs-mcp.py https://gtmlabs.io/mcp/gtm-labs-mcp.py

Step 2: Add to Your IDE

For Cursor, Windsurf, or Claude Desktop:

{ "mcpServers": { "gtm-labs": { "command": "python", "args": ["/Users/yourname/gtm-labs-mcp.py"] } } }

Step 3: Restart Your IDE

Completely quit and restart your AI IDE.

Step 4: Start Building!
